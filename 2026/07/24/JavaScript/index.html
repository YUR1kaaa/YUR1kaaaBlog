3、JavaScript基本语法

3.1 标识符

所谓标识符就是名字，JavaScript中标识符包括变量名、函数名、参数名、属性名、类名等

合法标识符（变量命名）规则：

①第一个字符必须是字母、下划线（_）或美元符号（￥）;

②除第一个字符外，其他位置可以使用Unicode字符。

③不能与js关键字、保留字重名

3.2 关键字和保留字

关键字（Keyword）有特定用途

保留字是javascript内部预备使用的一组名字，目前没有具体用途，是为js升级预备用的

3.3 大小写

JavaScript标识符严格区分大小写

5、定义变量

JavaScript用 var 关键字定义变量

可以一次定义多个变量，用逗号隔开

定义变量后默认初始值 undefined（未定义）

5.1 赋值

也可以在定义变量的同时赋值

5.2 let和const关键字

let 和 const 用于声明变量

let 声明的变量只在其所在代码块中有效，且在同一代码块中不能重复声明（类似局部变量）

const 的功能和 let 相同，但 const 定义的关键字不能修改（相当于定义的是常量）

6、JavaScript数据类型

6.1 数据类型

JavaScript中数据类型可分为两种：

基本数据类型（值类型）：字符串（String）、数字（Number）、布尔（Boolean）、空（Null）、未定义（Undefined）、Symbol；

引用数据类型：对象（Object）、数组（Array）、函数（Function）；

6.2 typeof操作符

使用 typeof 操作符返回变量数据类型

6.3 Symbol类型

ECMAscript6新引入，表示独一无二的值

Symbol类型的值需要使用Symbol（）函数生成

6.4 Object类型

JavaScript中的对象（object）类型是一组由键、值组成的无序集合，定义对象类型需要使用花括号{ }

其中name为键，value为值（类似python字典）

在JavaScript中，对象类型的键都是字符串类型的，值则可以是任意数据类型

可以使用 对象名.键 的形式获取对象中的某个值

6.5 Array类型

数组（Array）是一组按顺序排列的数据组合

数组中的每个值称为元素，数组中可以包含任意类型数据（类似python列表）

在JavaScript中定义数组用方括号[ ]，数组中元素使用逗号分隔

也可以使用 Array（） 函数创建数组

6.6 Function类型

函数（Function）是一段具有特定功能的代码块

函数不会自动运行，需要通过函数名调用

8、输出语句

JavaScript中提供了多种方式来向浏览器中输出内容：

① 使用 alert( ) 函数来弹出提示框；

② 使用 confirm( ) 函数来弹出一个对话框；

③ 使用 document.write( ) 方法将内容写入到HTML文档中；

④ 使用 innerHTML 将内容写入到HTML标签中；

⑤ 使用 console.log( ) 在浏览器的控制台输出内容;

8.1 alert( )与confirm( )

  • alert( )：仅弹出一个带单个”确定”按钮的纯文本提示框，是单向的信息告知，用户除了点击确定关闭弹窗外没有其他操作选项。
  • confirm( )：弹出包含“确定”和”取消”两个按钮的对话框，是双向的交互选择，用户可以自主选择确认或取消当前操作。

8.2 console.log( )

console.log( )将内容输出在控制台，常用来调试程序；

console.log( )输出的内容不显示在页面，需要F12打开检查;

8.3 innerHTML

与其他方法不同， innerHTML 是一个属性而非函数；

通过它可以设置或者获取指定HTML标签中的内容；

9.3 for循环语句

JavaScript中的for循环包含三个可选的表达式 initialization、condition、increment ，其中:

  • initialization：“初始化计数器变量”，声明一个表达式或变量，在循环过程中只会执行一次；

  • **condition**：条件表达式，与while循环中的条件表达式功能相同，

    ​ 通常用来与计数器的值进行比较，以确定是否进行循环，通过该表达式可以设置循环的次数;

  • **increment**：一个用于在每次循环后更新计数器的表达式；

① for循环的所有条件(三个表达式)写在同一行。

② for循环遍历数组

③ break语句（终止循环）

④ continue语句（跳出当前循环，开始下一次循环）;
